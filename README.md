# [Stargate: ReLeveled](https://www.curseforge.com/minecraft/modpacks/stargate-releveled)

**Stargate: ReLeveled** is a progression-focused Minecraft modpack built around exploration, automation, technology, and a healthy amount of questionable engineering decisions.

Explore the galaxy with **Stargate Journey** and **Ad Astra**, build automated factories with **Create** and **Mekanism**, and progress through a custom technology system that ties the entire pack together.

## Features

* **Stargate Exploration**
  Use [Stargate Journey](https://www.curseforge.com/minecraft/mc-mods/stargatejourney) and [Ad Astra](https://www.curseforge.com/minecraft/mc-mods/ad-astra) to travel between worlds and explore beyond the Overworld.

* **Custom Resource Progression**
  Generate resources through **Mystical Agriculture** and **BotanyBots**, using custom **Cruxes** to control resource production and progression.

* **Create > Mekanism > Oritech**
  Progress from mechanical automation into advanced industrial technology through custom recipes and processing chains.

* **Tiered Circuits**
  Build increasingly advanced electronics, from **Vacuum Tubes** and **Rudimentary Processors** to **MOSFETs**, **Integrated Circuits**, and **Computation Cores**.

* **Custom Progression**
  Recipes, resources, and technology have been heavily customized to make the pack's many mods work together as a cohesive progression.

* **Quest Book**
  Follow quests covering the pack's major systems and progression without being forced into a single playstyle.

* **Easy Mode**
  Use the Easy Mode Quest for a simplified progression path if you don't want to build an industrial empire just to craft a single circuit.

* **Multiplayer Friendly**
  Designed for both solo play and multiplayer, with a public community server available.
